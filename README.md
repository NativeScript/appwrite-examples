# Appwrite SDK Usage Examples

Usage examples for using the [Appwrite SDK](https://appwrite.io/docs/sdks).

Prerequisites:
- [NativeScript Environment Setup](https://docs.nativescript.org/environment-setup.html)
- node >=20 

```bash
npm run setup
```

## Run Example Apps

Register an Appwrite account [here](https://appwrite.io/) and create a project to gather your endpoint and project id.

Setup a `.env` file at the root of any of the demo apps within `apps/demo-*` with the following:

```base
APP_WRITE_ENDPOINT=https://[YOUR_APPWRITE_ENDPOINT]
APP_WRITE_PROJECT_ID=[YOUR_APPWRITE_PROJECT_ID]
```
